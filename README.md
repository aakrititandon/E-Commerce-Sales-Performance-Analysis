# E-Commerce Sales Performance Analysis

## Overview
Analyzed e-commerce retail data to identify sales trends, customer demographics, 
and channel performance using Microsoft Excel.

## Key Insights
- Amazon was the top performing sales channel at 35%
- Maharashtra was the highest revenue generating state at ₹2.99M
- Women accounted for 64% of total orders
- 92% of orders were successfully delivered

## Tools Used
- Microsoft Excel (Pivot Tables, VLOOKUP, Conditional Formatting)
- Interactive Dashboard with Slicers
- Data Visualization (Bar, Pie, Line Charts)

## Dashboard Features
- Monthly sales trend analysis
- Gender-wise and age-wise order breakdown
- Top 5 states by revenue
- Channel-wise order distribution
- Order status summary
